# Protocol and measurement boundaries

The active comparison is the September 28 six-stack sweep with the September 29 recommended-thinking HermesAgent-20 correction. The explicit panel whitelist is in `benchmark/active-sweep-contract.json`. HumanEval/0–9, recommended Tools TC70–84, two HermesAgent-20 passes plus their separate required smoke, cold/append prefill, full-vocabulary fidelity, and resource records comprise the selected scope. Full HumanEval, Core-19 and unrelated long-output tests are outside it.

Each requested benchmark ran once. Required unscored warmup, primers, transport probes and Hermes smoke remain labeled separately. The prompt order, hashes, modes, seeds, concurrency, output rules, timeouts, retry policy and clock boundaries were frozen before requests. Request and scope validators ran before generation. Each model retains its own pinned card sampler and serving recommendations; equal conditions do not require forcing a common temperature.

For Strata, Tool-Eval uses recommended nonthinking settings: temperature 0.7, top-p 0.8, top-k 20, min-p 0, presence penalty 1.5 and repeat penalty 1, seed 123. Hermes uses recommended thinking settings: temperature 1.0, top-p 0.95, top-k 20, min-p 0, presence penalty 0, with frozen per-pass seeds and preserved thinking. The raw counting panel uses `/v1/completions` and its inherited base-card default sampler, independent of chat thinking controls. Consult the actual locks and per-request records for effective settings.

Strata is pinned to commit `1735d6471df29b42c26170efaac1f1446a58640f`, release v0.1.40. ROCm 7.14.1 / gfx1151, 262,144 context, 16,384 prefill chunk, int8 KV, resident experts, MTP spec4, MTP Q4 all and lookup chain3. Optional kernels that change numerics remain off; all 64 HIP compilation commands use O3 and NDEBUG. Fidelity is target-only with spec2, required by IQ-pack startup, and no MTP. Unoptimized and missing-spec startup diagnostics remain infrastructure evidence, excluded from scored results and replay durations.

The corrected prefill sweep reuses precisely D cached tokens, reads precisely P new tokens, and rejects missing exact-depth cache state before any prefill. The completed primer state is snapshotted without generation outside the timed append. All 18 scored cells have zero cached-prefix replay. The superseded periodic-checkpoint experiment remains diagnostic. First malformed counting outputs were preserved without retry; 2/18 cells produced clean counting. Native PP remains a processing measurement; decode rates for malformed output are diagnostic.

Strata native TG uses generated/decode-ms, including first prediction and terminal EOS. Its native PP counts the final input token while that token's work is charged to decode. Llama-based historical HE native TG uses `(n−1)/time`; Gufo and Halogen use `n/time`. The client request wall is recorded separately. Historical cache/lookup histories and serving lifecycles remain in the source; Carlos's prior resident lookup history is unrecovered. Mixed clocks or lifecycles do not prove a controlled engine-only gain.

Hermes replay includes all 20 ordered cases in each pass. Mean replay averages corresponding per-case walls and points. The API comparator reuses two saved complete passes, with the explicitly authorized HA-04 adapter correction in pass 1. It sums scored case walls and excludes between-case operator repair pauses. Tool replay has 15 cases and displays official points out of 30; its published percentage is rounded. ROCmFPX2's official 73/100 and separately reviewed 80/100 remain distinct.

Execution audits match actual agent tool-call records, IDs, names and arguments to completed environment events and observations: 49 Tool-Eval executions and 250 Hermes primary executions across 40 scored Strata cases. A tool mentioned in a task is not counted as execution.

Fidelity compares a common saved BF16 teacher against all 248,320 vocabulary logits at the last 128 positions of each of 16 frozen 512-token windows: 2,048 rows. The scalar results, input windows, capture/scoring code and binary archive hashes are included. The multi-gigabyte binary capture remains in the private benchmark archive.

Serving assets include weights, native pack and MTP with inode deduplication, excluding SDK/build caches. Strata host pressure is the peak MemAvailable drop from the post-production-stop pre-load sample. Ready/peak host-used RAM and minimum available RAM are retained separately. Historical memory methods differ, including Halogen pinned allocations. RAM, GTT, VRAM and RSS overlap on UMA and must not be added.

Full requests, responses, native timing records, memory samples, locks, source receipts and outcomes accompany the publication. Privacy redactions have separate public hashes, preserve numerical JSON/JSONL values, and are described in the publication manifest. No publication step reruns a model.
